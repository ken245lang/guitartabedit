📌 概要

本アプリはブラウザだけで動作する ソロギター用タブ譜エディタ です。タブ譜の作成・編集・再生に加え、ネック上の音配置を確認できる「ネックビジュアライザー」、コード譜画像を並べて印刷できる「コード譜ビルダー」を搭載しています。インストール不要・データは端末内でのみ処理されます。

💡 推奨ブラウザ: Chrome / Edge（保存先フォルダ選択など一部機能はこの2つのみ対応）。Firefox / Safari でも基本機能は動作します。

🔀 ビュー切替

画面左上で2つのビューを切り替えられます。

  • 📝 タブ譜エディタ — 6弦タブ譜の作成・編集・再生
  • 🎸 ネック・コード譜 — 指板表示 / コード譜画像のレイアウト

右側の ⚖️ ご利用上の注意 と 📖 使い方 はどちらのビューでも常時アクセスできます。

📝 タブ譜エディタ ─ 楽譜の基本設定

行数 / 分割
  • 行数: 1〜30行。1行 = 4小節
  • 分割: 1小節を等分する数（4 / 6 / 8 / 16）。8 = 8分音符グリッド、16 = 16分音符グリッド
  • 変更後は 適用 で反映（既存データは保持されます）
＋行 / −行 / 全消去
  • +行: 末尾に空の1行（4小節）を追加
  • −行: 末尾の1行を削除（最低1行は残ります）
  • 全消去: 譜面全体をクリア（確認ダイアログあり）

🛠 ツール（編集モード）

左上の3つのツールボタンで動作モードを切り替えます。

  • 数字入力: タブセルをクリック → ポップアップで 0〜24 を入力 → OK または Enter。空欄で OK すると消去
  • コード配置: 下部の「コード選択バー」で組んだコードを、コード行のセルにクリックで配置
  • 消去: タブの数字 / 配置済みコード名をクリックして削除
  • 範囲選択: 小節をクリックして選択開始。Shift+クリックで矩形範囲（複数行×複数小節）に拡張
💡 タブの数字をクリックすると（ツールに関係なく）その音が鳴って試聴できます。

📋 範囲選択・コピー＆ペースト

同じフレーズの繰り返し（A→A'、サビの反復など）を効率よく入力するための機能です。小節データ（タブの数字＋コード）をまとめて複製できます。

範囲を選ぶ
  • 小節単位: ツールを 範囲選択 に切替 → 小節をクリック → 別の小節を Shift+クリックで矩形範囲に拡張
  • 行単位: 各行の左にある #1 #2 … の 行ハンドル をクリック（ツールに関係なくいつでも使用可）。Shift+クリックで複数行に拡張
  • 選択中の小節は水色の点線枠で表示されます
コピー＆ペースト
  1. 範囲を選択
  2. 📋 コピー ボタン または Ctrl+C
  3. 貼り付け先の開始小節を範囲選択（1小節クリックでOK）
  4. 📥 貼り付け ボタン または Ctrl+V
動作のポイント
  • 貼り付けは 選択範囲の左上を起点 に、コピーした矩形の形そのままで配置されます
  • 貼り付け先で行数が足りない場合は 自動的に行が追加 されます
  • 1行の右端（4小節目）を超える列はクリップされます
  • 貼り付け先の既存データは 上書き されます（部分マージはしません）
  • Esc で選択を解除
  • クリップボードはアプリ内専用です（OSのクリップボードとは独立）。ページを再読み込みすると消えます
💡 入力欄（行数 / BPM など）にフォーカスがあるときは Ctrl+C/V は通常のテキスト操作として動きます。譜面コピペには譜面エリア側にフォーカスがある状態で押してください。

🎵 転調 / カポ

ヘッダーの 🎵 転調 から、半音単位またはキー指定で曲全体を転調できます。「カポ方式」と「データ書き換え方式」の2つから選べます。

転調量の指定
  • 半音: − ＋ ボタンか直接入力で −12〜+12 半音
  • キー: 「現在のキー → 転調先キー」のドロップダウンで指定すると半音数が自動計算されます（最短方向で正規化、±6半音以内）
  • どちらを操作してももう一方が連動して更新されます
🎸 カポ方式（推奨：表示のみ）

譜面データは一切変更せず、コード名の表示と再生音だけを N 半音上げます。フレット番号と運指は元のまま。

  • 例: C キーの曲に カポ +2 を適用 → コード名は D / Em / G / A … と表示。フレット番号は変わらず、再生は2半音上で鳴る
  • ヘッダーに Capo +N バッジが表示されます。バッジをクリックでカポ解除
  • カポ値は保存ファイル（.json）にも保持されます
  • 譜面エディタ上で新規にコードを配置するときは 元キー（カポ無し相当） のコード名で入力してください。表示は自動でカポ分シフトされます
📝 データ書き換え方式

全フレット番号とコード名を 実際に書き換え ます。譜面そのものを別キーに作り変えたい場合に使います。

  • 全フレットに半音数を加算（例: +2なら 3F → 5F）
  • 0〜24 フレット範囲外になる音がある場合は事前に警告。続行するとクランプされます（0未満→0、25以上→24）
  • 元に戻したい場合は逆方向（−N）で再度適用
  • Undo はありません。実行前に保存しておくと安全です
⚠ カポ方式とデータ書き換え方式は併用可能ですが、混在すると混乱しがちです。基本はどちらか一方に統一して使うのがおすすめです。
💡 弾き語りや合奏でキー変更が必要なときは「カポ方式」、ソロギターで別キーの譜面を作りたいときは「データ書き換え方式」が向いています。
フレット番号の転調について（補足）

「コードは転調できても数字（フレット番号）は難しいのでは？」と思われがちですが、内部処理はシンプルです:

  • カポ方式: フレット番号は触らず、再生時に fret + capo として発音。同じ運指のまま音だけ上がるので、譜面の数字を読み替える必要がありません
  • データ書き換え方式: 全フレットに +N を加算するだけ。同じ弦のままポジションが動くので、運指の形は概ねそのまま使えます（高フレットすぎると弾きづらくなる場合あり）

本アプリでは「弦をまたいで同じポジションに収める」自動最適化は行いません。自動で弦移動すると音色（弦のキャラクター）が変わり、和声バランスも崩れやすいためです。ポジションを動かしたい場合は転調後に手動で編集する想定です。

💡 +N後に数本だけ24フレットを超えたなど局所的に困ったときは、範囲選択＋コピペで他の場所のフレーズを流用したり、その小節だけ手作業で1オクターブ下げる（−12）と素早く整えられます。
ユースケース別の選び方
  • 弾き語り・歌の伴奏でキーを上下したい → カポ方式（実際にカポを付ければそのまま使える）
  • セッションで「半音上げて」と言われた → カポ方式（即時切替、データを汚さない）
  • 原曲のキーが弾きにくい / 別キーで譜面を仕上げたい → データ書き換え方式
  • とりあえず色々試したい → カポ方式で確認 → 確定したらデータ書き換え方式

🎼 コード選択バーの使い方

2行目バーで「コード」「変音」「オンベース」「タイプ」を組み合わせて構築します。右端の「選択中」が現在のコード名です。

  1. コード: ルート音（C / D / E / F / G / A / B）
  2. 変音: ♮ ナチュラル / ♭ フラット / ♯ シャープ
  3. オンベース: 分数コード（スラッシュコード）の最低音。「なし」を選べば通常コード。
    例: ルート=C + オンベース=E → C/E
  4. タイプ: M / m / 7 / M7 / m7 / mM7 / dim / dim7 / m7♭5 / aug / sus2 / sus4 / 6 / m6 / add9 / 9 / M9 / m9 / 11 / 13 / 7♭5 / 7♯5 / 7♭9 / 7♯9 / 7♯11

構築できたら、ツールを「コード配置」に切り替え、譜面のコード行（弦より上の薄い行）でクリックして配置します。コードは小節内の任意の分割位置に置けます。

🎨 表示モード・コードトーン彩色

黒文字 / コードトーン彩色
  • 黒文字: すべての数字を黒で表示（標準）
  • コードトーン彩色: 直前のコードに対する音程関係で数字を色分け
🎨 色設定

コードトーン彩色の色をユーザー設定できます。次の5種類を任意の色に変更可能（カラーピッカー）。

  • ルート (1度): コードのルート音 / 分数コードの場合はベース音も同色
  • 3度: 短3度（m3）・長3度（M3）
  • 5度: 完全5度・減5度・増5度
  • 7度: 短7度・長7度
  • その他のコードトーン: 9th / 11th / 13th / 6th / sus音など

デフォルト: 赤 / オレンジ / 緑 / 青 / 青。設定はブラウザに自動保存（localStorage）され、次回起動時も復元されます。「デフォルトに戻す」ボタンで初期化できます。

💡 コードトーン外（非構成音）は常に黒のままです。表示モードを「黒文字」にすれば一切色付けされません。

▶ 再生機能

BPM

20〜300 の範囲で指定。分割数に応じて1音の長さが自動計算されます。

再生開始位置

各行上部の 点線バー をクリックすると、その位置に ▼マーカー が立ち、再生開始位置になります。最初の行・小節・分割から始めたい場合は左端をクリック。

再生 / 停止
  • ▶ 再生: 開始位置から最後まで再生。再生中はカーソルがハイライトされます
  • ■ 停止: 即座に全音をカット
音色

Karplus-Strong 法によるギターシンセを内蔵。弦ごとに減衰特性とローパスフィルタを変えてアコースティックギターらしい鳴りを再現しています。

💾 保存・読込・印刷

  • 💾 保存: 譜面を .json で書き出し（ファイル名はプロンプトで指定）
  • 📂 読込: 保存済みの .json を読み込み
  • 印刷: ブラウザの印刷ダイアログを開く。ヘッダー・コードバー・操作UIは自動的に非表示になり、譜面のみが用紙にレイアウトされます
⚠ 全消去・読込で上書きされる前にこまめに保存してください。Undo/Redo は実装されていません。

🎸 ネック・コード譜 ビュー（タブ1: ネックビジュアライザー）

指板上のコード構成音を可視化するツールです。コードを選ぶと24フレット分の指板にすべてのポジションが表示されます。

コードの組み方
  1. 「ルート音」「変化記号」「コードタイプ」を選択
  2. 必要なら「ベース音（分数コード）」を指定（変化記号も別途）
  3. コード名と構成音ピルが表示されます（赤=ルート / 青=構成音 / 橙=ベース）
表示の調整・保存
  • フレット幅スライダーで指板の拡大／縮小
  • 保存 開始フレット〜終了フレット: 一部フレット範囲だけ画像に切り出して保存可能
  • 📁 選択でフォルダを指定（Chrome / Edge のみ） → 指定フォルダへ直接書き出し
  • 未指定なら通常のダウンロードフォルダに保存
  • 💾 PNG / 💾 JPEG で書き出し

📄 ネック・コード譜 ビュー（タブ2: コード譜ビルダー）

上記ネックビジュアライザーで保存した画像（または手持ちの画像）を並べて、印刷可能なコード譜を作るツールです。

  1. 📁 フォルダから読み込むでコード画像を一括ロード（PNG / JPG / GIF / WEBP）
  2. パレットから クリックで末尾追加 / ドラッグで任意の位置に挿入
  3. 譜内の項目もドラッグで並べ替え可能。コード名（画像下のテキスト）はクリックで編集
  4. ↩ 改行追加でフレーズを段組み
  5. 曲名を入力 → 🖨 印刷でPDFや紙に出力
💡 画像の高さは「譜サイズ」スライダーで一括調整できます（小〜大）。

💡 ヒント・トラブルシューティング

音が鳴らない
  • ブラウザのオーディオは初回操作後に有効になります。一度ボタン操作してから再生してください
  • OS / ブラウザの音量、タブのミュート状態を確認
色設定が反映されない
  • 「表示」モードが「コードトーン彩色」になっているか確認
  • そのセルの位置に有効なコードが配置（または直前の小節以前に存在）しているか確認
分数コードの色付け

例 C/E の場合、E はベース音なので「ルート色」で塗られます（コード本体のルート C も同色）。

ネックビュー/コード譜ビューに切替えても譜面データは消えません

iframe で完全分離しているため、両ビューのデータは独立。タブ譜エディタの内容は保持されます。

データはどこに保存される？

譜面本体は端末上の任意の場所に .json として書き出し。色設定はブラウザの localStorage に保存されます（このブラウザ・このドメインに限定）。
